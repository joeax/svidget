# Svidget

Svidget is a modern JavaScript library designed to create and manage interactive SVG widgets on web pages. It provides a structured way to handle widget lifecycle, events, and communication between widgets and the host page.

This document will focus on building highly usable and visual SVG widgets using Svidget.
